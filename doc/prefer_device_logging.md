# Device logging

The `klint::prefer_device_logging` lint warns about kernel `pr_*` macros when a
shared device reference is in scope. Device logging includes information about
the device, which helps identify the source of a message on systems with more
than one device of the same kind.

For example, instead of:

```rust,ignore
fn probe(dev: &kernel::device::Device) {
    kernel::pr_info!("starting device\n");
}
```

prefer:

```rust,ignore
fn probe(dev: &kernel::device::Device) {
    kernel::dev_info!(dev, "starting device\n");
}
```

The check recognizes the kernel's exported logging macros, including renamed
imports. It also recognizes shared references to types implementing
`AsRef<kernel::device::Device<_>>`, such as bus-specific device wrappers.
Lexical scopes and shadowing are respected.

This lint is advisory: the presence of a device does not prove that a particular
message is about that device, so no automatic fix is offered. If generic logging
is intentional, allow the lint on the enclosing function or block.

The initial implementation does not look for devices in fields, owned values,
mutable references, or declarations without initializers. It does not inspect
logging generated by other macros, `pr_cont!`, or the `pr_*_once!` macros.
